# ⏳ Countdown Events App



## Features

✨ **Multiple Event Tracking** - Add and manage as many events as you want
📸 **Photo Upload** - Add a custom photo for each event
⏱️ **Live Countdown** - Real-time countdown showing days, hours, minutes, and seconds
📊 **Progress Tracking** - Visual progress bar showing how close you are to each event
💾 **Data Persistence** - Your events are saved locally in your browser
📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
🎨 **Beautiful UI** - Modern design with smooth animations

## How to Use

1. **Add an Event**
   - Enter the event name (e.g., "Summer Vacation")
   - Select the target date
   - (Optional) Upload a photo for the event
   - Click "Add Event"

2. **View Countdowns**
   - Each event displays days, hours, minutes, and seconds remaining
   - Progress bar shows how far through to the event you are
   - Status indicator shows if it's upcoming, today, or passed

3. **Manage Events**
   - Click "Delete" to remove an event
   - All changes are automatically saved

## Technology Stack

- **HTML5** - Semantic structure
- **CSS3** - Beautiful styling with gradients and animations
- **Vanilla JavaScript** - No dependencies, lightweight
- **localStorage** - Browser-based data persistence

## Installation & Deployment

### Option 1: GitHub Pages (Recommended)

1. Fork or clone this repository
2. Go to Settings → Pages
3. Select "Deploy from a branch"
4. Select `main` branch and `/root` folder
5. Your site will be live at `https://yourusername.github.io/countdown-app`

### Option 2: Local Testing

Simply open `index.html` in your web browser!
